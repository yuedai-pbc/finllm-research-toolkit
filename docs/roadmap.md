# Roadmap

- Organize the Financial LLM survey PDF.
- Build a structured paper taxonomy.
- Add macroeconomic research task templates.
- Draft RAG and agent workflow notes.

## Phase 2: Reproducible Templates

- Add public-source document ingestion examples.

- Add evaluation rubrics for financial reasoning and citation quality.

## Phase 3: Lightweight Demonstrations

- Build a small RAG demo using public documents.
- Build an agent workflow demo for literature mapping.
- Add examples of evidence-grounded macro research summaries.

## Phase 4: Collaboration

- Invite feedback on taxonomy, methodology, and evaluation design.
- Add issue templates for papers, datasets, and workflow suggestions.
